# Per-Feature Status Documentation

Each team member (`P1` through `P5`) must maintain a feature status document in this directory for every assigned stage.

### File Naming Convention
`<TAG>_stage<STAGE>_<SHORT_NAME>.md`

Examples:
- `P1_stage1_synthetic-detector.md`
- `P2_stage3_detect-endpoint.md`
- `P3_stage4_pipeline-orchestration.md`
- `P4_stage5_dropzone-upload.md`
- `P5_stage6_forensics-dashboard.md`
